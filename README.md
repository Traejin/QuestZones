# QuestZones

Quest tracker for World of Warcraft Forever, grouped by zone, in Blizzard's style. Replaces the Blizzard objective tracker.

## Features
1. All quest log quests grouped by zone, current zone first.
2. Collapse the whole tracker, a zone (click its header) or a quest (Ctrl-click).
3. Titles colored by difficulty, with completed quests marked "(Complete)".
4. Quest item buttons included.
5. Mouse-wheel scrolling.

## Note
Compatible with Spoken's quest Play button.
