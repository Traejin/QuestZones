# QuestZones

Quest tracker for World of Warcraft: Forever, grouped by zone, in Blizzard's style. Replaces the Blizzard objective tracker.

## Features
1. All quest log quests grouped by zone, current zone first.
2. Collapse the whole tracker, a zone (click its header) or a quest (Ctrl-click).
3. Titles colored by difficulty; completed quests marked "(Complete)".
4. Quest item buttons, usable in combat.
5. Mouse-wheel scrolling.
6. Compatible with Spoken's quest Play button.

## Usage
1. Left-click a quest: open it on the map.
2. Shift-click: link it in chat.
3. Right-click: focus, show on map, stop tracking, share, abandon.
4. Position and height: Edit Mode, Objective Tracker.

## Install
Extract the `QuestZones` folder into `World of Warcraft\_forever_\Interface\AddOns`.
Questie users: disable Questie's own tracker.
